# Extension Icons

This directory should contain the following icon files:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

You can create these icons using:

1. **Online Tools**:
   - [Favicon Generator](https://www.favicon-generator.org/)
   - [RealFaviconGenerator](https://realfavicongenerator.net/)

2. **Image Editors**:
   - GIMP, Photoshop, or any image editor
   - Create a simple icon with "n8n" or "Git" theme
   - Export at the required sizes

3. **Quick Solution**:
   - Use any 128x128 PNG image
   - Resize it to 48x48 and 16x16 for the other sizes
   - Name them accordingly

## Temporary Placeholder

Until you create proper icons, you can use any PNG image files with the correct names. The extension will work without icons, but Chrome may show a default icon.
